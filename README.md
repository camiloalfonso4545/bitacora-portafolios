# Bitácora de Portafolios

Lectura visual e interactiva de *Secretos para dominar la gestión de portafolios de programas y proyectos* (Liliana Buchtik, 2.ª ed. en línea, 2025), preparada por Camilo para la materia Gestión de Portafolios de la Maestría en Gerencia de Proyectos.

Ver la página: https://camiloalfonso4545.github.io/bitacora-portafolios/

Se publica por entregas: cada una activa nuevos capítulos. Los textos son resúmenes y diagramas propios; las figuras originales pertenecen a la autora.

Fuente: Buchtik, L. (2025). *Secretos para dominar la gestión de portafolios de programas y proyectos* (2.ª ed., versión en línea). Buchtik Global.
